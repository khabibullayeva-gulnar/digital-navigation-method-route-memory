# Methodology Passport Card

## Project Information
**Project Title:** The Effect of Digital Navigation Method on Route Memory in Young People: A Comparison of Turn-by-Turn Directions and Prior Study of a Digital Map

**Author:** Gulnar Khabibullayeva

**GitHub Repository:** https://github.com/khabibullayeva_gulnar/digital-navigation-method-route-memory

## Research Type
This study uses a quantitative experimental design. It compares two navigation conditions and measures route-memory performance using numerical accuracy scores.

## Hypotheses
**H0:** There is no significant difference in route-memory accuracy between participants using turn-by-turn digital guidance and participants who study a digital map before navigation.

**H1:** Participants who study a digital map before navigation demonstrate higher route-memory accuracy than participants using turn-by-turn digital guidance.

## Variable Matrix

### Independent Variable
Digital navigation method:
- Turn-by-turn guidance
- Prior study of a digital map

### Dependent Variables
- Direction recall accuracy (%)
- Landmark recognition accuracy (%)

### Controlled Variables
- Same unfamiliar walking route
- Same start and finish points
- One route traversal
- Same testing interval
- Same scoring rules
- Same instructions within each condition

## Metrics and Baseline

**Primary Metric:** Direction recall accuracy (%)

**Secondary Metric:** Landmark recognition accuracy (%)

**Guardrail Metrics:**
- Complete participant data
- No additional navigation assistance during testing
- Same route exposure for all participants
- No critical data-processing errors

**Baseline:** Turn-by-turn navigation group

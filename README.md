# The Effect of Digital Navigation Method on Route Memory in Young People

## Authors
Gulnar Khabibullayeva

## Full Research Title
The Effect of Digital Navigation Method on Route Memory in Young People: A Comparison of Turn-by-Turn Directions and Prior Study of a Digital Map

## Overview
This project investigates how two digital navigation methods influence route memory in young people. The study compares turn-by-turn guidance with prior study of a digital map. Route memory is evaluated using direction recall accuracy and landmark recognition accuracy.

## Research Question
How does the digital navigation method—turn-by-turn directions or prior study of a digital map—affect route memory in young people?
